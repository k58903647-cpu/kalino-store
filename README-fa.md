# کالینو — نسخه واقعی فروشگاهی

این پروژه از حالت «یک فایل HTML» خارج شده و یک فروشگاه فول‌استک قابل استقرار است:

- Node.js + Express
- SQLite برای دیتابیس
- ورود/ثبت‌نام مشتری
- سبد خرید
- ثبت سفارش و کاهش موجودی
- پنل مدیریت جداگانه
- مدیریت کالا، موجودی، سفارش و کاربران
- تنظیمات فروشگاه
- آپلود عکس در پوشه uploads
- طراحی فارسی و موبایل‌پسند

## اجرای محلی

1. Node.js نسخه 20 یا جدیدتر نصب کن.
2. داخل پوشه پروژه ترمینال باز کن.
3. بزن:

```bash
npm install
npm start
```

4. مرورگر را روی `http://localhost:3000` باز کن.

## ورود مدیر اولیه

ایمیل: `admin@kalino.ir`

رمز: `Kalino@12345`

**قبل از عمومی‌کردن سایت، رمز و JWT_SECRET را در متغیرهای محیطی تغییر بده.**

## آنلاین کردن

این پروژه برای سرویس‌های میزبانی Node.js قابل استقرار است. بعد از قرار دادن پروژه روی سرور، دستور `npm install` و سپس `npm start` اجرا می‌شود. برای دامنه واقعی نیز دامنه را به سرور وصل می‌کنی.

### متغیرهای مهم محیطی

- `PORT`
- `JWT_SECRET`
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `NODE_ENV=production`
