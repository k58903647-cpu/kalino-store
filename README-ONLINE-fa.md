# کالینو — بسته آماده انتشار آنلاین

این پروژه آماده استقرار Node.js/Docker است.

## قبل از انتشار
متغیرهای زیر را تنظیم کن:
- `NODE_ENV=production`
- `JWT_SECRET` یک رشته تصادفی طولانی
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `PORT` توسط سرویس میزبانی تعیین می‌شود

## نکته مهم دیتابیس
این نسخه از SQLite استفاده می‌کند و فایل دیتابیس در `data/kalino.db` ساخته می‌شود. برای سایت واقعی باید هاست دارای **Persistent Disk/Volume** باشد؛ وگرنه ممکن است با ری‌استارت یا دیپلوی مجدد اطلاعات از بین برود.

## اجرای محلی
```bash
npm install
NODE_ENV=production JWT_SECRET='یک-رشته-خیلی-طولانی' ADMIN_EMAIL='admin@kalino.ir' ADMIN_PASSWORD='یک-رمز-قوی' npm start
```

## ورود مدیر
از ایمیل و رمزی که در `ADMIN_EMAIL` و `ADMIN_PASSWORD` تعیین کرده‌ای استفاده کن.
